BlogSphere:

BlogSphere is a full-stack blog platform where users can create an account, log in securely, create and manage blogs, publish content, and interact with blogs through comments.

Features:
User Registration
User Login
JWT-based Authentication
Protected Routes
MongoDB Database Integration
Create Blog
Edit Blog
Public Blog Listing
Blog Details Page
Blog Categories
Blog Tags
Featured Blog Images
Comments System
Author Information
Dashboard / My Blogs
Published Blog System
Responsive Design
Desktop
Tablet
Mobile
Frontend and Backend API Integration
Tech Stack
